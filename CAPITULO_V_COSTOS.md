# COSTO DE IMPLEMENTACIÓN DE LA INNOVACIÓN / MEJORA / CREATIVIDAD

En el presente proyecto de mejora, orientado al desarrollo e implementación de un sistema ERP para la gestión integral de ventas de vehículos, se consideró un periodo total de ejecución de cuatro meses. El sistema incluye módulos de gestión de clientes, inventario de vehículos, cotizaciones, pagos, créditos, entregas, y un chatbot con inteligencia artificial para atención al cliente. El cálculo de costos comprende todos los recursos necesarios para el desarrollo, implementación y puesta en marcha del sistema.

### Cálculo de contingencias

**Fórmula:**
```
Costo base sin contingencias = Materiales + Mano de Obra + Equipos + Otros (sin contingencias)
Contingencias = Costo base sin contingencias × Factor de contingencia (5%)
```

**Cálculo:**
```
Costo base sin contingencias = S/. 444.60 + S/. 3,515.88 + S/. 6,358.00 + S/. 3,598.60
Costo base sin contingencias = S/. 13,917.08

Contingencias = S/. 13,917.08 × 0.05
Contingencias = S/. 695.85 ≈ S/. 696.00
```

*Nota: Se redondea a S/. 696.00 para facilitar el cálculo y mantener un margen conservador.*
